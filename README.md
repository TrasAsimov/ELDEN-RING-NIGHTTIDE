# ELDEN RING: NIGHTTIDE
### 艾尔登法环：黑夜入侵

[简体中文](README.zh-CN.md) · [Roadmap](ROADMAP.md) · [Credits](CREDITS.md)

**ELDEN RING: NIGHTTIDE** is an independent Elden Ring overhaul focused on redesigned progression, combat balance, world encounters, and selected Nightreign boss integrations across the Lands Between and the Realm of Shadow.

NIGHTTIDE originally began as a personal rebalance experiment inspired in part by **Elden Ring Ascended**. As development expanded, it evolved into an independently designed overhaul with its own balance philosophy, progression structure, encounter design, boss placement, and additional content.

Special thanks to **vanbuinen and Elden Ring Ascended** for the inspiration behind the project's early development.

> **Public build:** Not yet available.  
> This public repository currently contains project information and development planning only. No game files or downloadable build are being distributed here at this stage.

## Project direction

NIGHTTIDE aims to:

- Rework progression and combat balance without relying on a single global difficulty multiplier.
- Strengthen underperforming melee options, equipment, talismans, items, and build archetypes.
- Rework selected encounters, rewards, boss placement, and world progression.
- Integrate selected Nightreign bosses into locations that fit their scale, theme, and combat requirements.
- Preserve the identity of Elden Ring while creating a more dangerous, replayable late-game experience.
- Keep third-party integrations clearly credited and permission-aware.

## Development status

The project is under active development. Current work includes balance migration, encounter design, Nightreign boss integration, world placement, compatibility work, and runtime testing.

The internal development build and historical test packages are kept separately from this public repository. A public download will only be published when the standalone NIGHTTIDE build is ready for distribution.
