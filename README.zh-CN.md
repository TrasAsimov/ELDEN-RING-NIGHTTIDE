# ELDEN RING: NIGHTTIDE

## 艾尔登法环：黑夜入侵

[English](README.md) · [安装说明](INSTALL.md) · [已知问题](KNOWN_ISSUES.md) · [更新日志](CHANGELOG.md) · [致谢](CREDITS.md)

NIGHTTIDE 是一个仍在开发的《艾尔登法环》整合重制 Mod，包含成长和平衡调整、遭遇修改，以及部分《黑夜君临》Boss 的整合。

**当前版本：v0.10.38 公测版 2（`v0.10.38-beta.2`）。** 请到 [GitHub Releases](https://github.com/TrasAsimov/ELDEN-RING-NIGHTTIDE/releases) 下载完整玩家 ZIP `ELDEN_RING_NIGHTTIDE_v0.10.38_Public_Beta_2.zip`。GitHub 自动生成的 “Source code” 附件只有仓库文档，不是游戏安装包。

本版整理 F8.x 之后的现行公测目录。大嘴抓取锁定时机与平地离场重置（F8.4 / F8.4.1）已实机验证，离场区距标记 `2054390850` 为 54 m。山羊挥击幅度与不得其名一阶段打击感、音效仍未修好，相关工作已暂停。F9 对 `cs_smain.bnk` 的试验曾使全部 Boss 音乐无声，已回滚原版 bank；未附带黑夜君临 OST。请先阅读 [已知问题](KNOWN_ISSUES.md)。

## 安装

需要《艾尔登法环》本体、黄金树幽影 DLC，以及另行安装的 ME3。开发基线针对游戏 1.17.1，其他版本的兼容性未验证。完整解压到全新目录，运行 `ModEngine/launchmod_eldenring.bat`。不要叠加公测版 1 或更早的测试包，详见 [安装说明](INSTALL.md)。

配置默认离线启动。测试整合 Mod 前请备份存档。本轮实机核对仅覆盖上面写明的大嘴抓取锁定与平地离场。山羊、不得其名、音乐替换和其他未关闭的遭遇不在该确认范围内。
